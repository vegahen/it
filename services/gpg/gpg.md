# GnuPG

https://gnupg.org

## Install - macOS

### Install

```sh
brew install --formula gnupg
```

### Homebrew dependencies

```yaml
gnupg:
- ca-certificates
- gmp
- libunistring
- json-c
- gettext
- libidn2
- libtasn1
- nettle
- p11-kit
- gnutls
- libgpg-error
- libassuan
- libgcrypt
- libksba
- libusb
- npth
- pinentry
- readline
```
